# 岗位目录整体方案（一级 → 二级 → 三级 → 具体岗位）

## 目录原则

1. 一级为岗位大类，二级为职业方向，三级为预先定义的细分岗位类别，四级为原始具体岗位。
2. 三级类别先定义，具体岗位随后映射；无法归属的进入该二级方向的“其他岗位”。
3. 只有具备两个及以上明确职业分工的二级方向才显示三级；其余暂时直达四级，不以通用名称硬拆。
4. 下列“已定义三级”是当前可审阅的目录；“待细分”表示需要先补充专业三级词表，再统一安排具体岗位。
