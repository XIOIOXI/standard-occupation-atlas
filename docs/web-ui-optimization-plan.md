# 网页端统一优化方案

## 目标与边界

面向毕业生，让职业探索、岗位查找和来源核查形成连贯体验。覆盖当前 React 前端的全部活动页面与共享弹层；历史保留但未挂载的课程或技能页面不新增产品入口。

不改招聘原始数据、分类体系、统计逻辑或模型调用边界，不增加账号、匹配、申请看板或对话助手。不读取完整招聘源数据。

## 设计方向

采用「职业图鉴编辑部」方向：保留黑底气泡图的识别性，用暖白文字、低饱和绿色操作色与少量橙色强调建立秩序。对比过全站浅色目录、传统卡片仪表盘后，选择延续现有图鉴，降低认知切换和图表改造风险。

中文采用本地可用的苹方／微软雅黑字体回退，正文优先清晰阅读；标题缩小过度负字距，长职业名称完整换行。集中维护背景、文本、边框、状态、间距和组件变量。阅读区与图形区共享颜色体系，减少大标题对有效内容的挤压。

## 页面与验收范围

| 页面或区域 | 优化内容 | 验收方式 |
| --- | --- | --- |
| 全局导航 | 显式职业图鉴、岗位搜索、每日新增入口；管理入口弱化；当前页、键盘焦点、窄屏换行 | 切换各页并核对激活状态；键盘与窄屏检查 |
| 职业图鉴及逐级目录 | 保留气泡探索；优化标题、控制区、面包屑和列表阅读；避免遮挡 | 根目录与下钻页面桌面／窄屏视觉检查；现有布局测试 |
| 分类与职业详情 | 统一标题、统计、地点分布、来源列表的层级与间距 | 详情路径及来源链接检查 |
| 岗位搜索 | 突出关键词与地点；统一筛选、分类面板、状态和结果列表 | 搜索、组合筛选、清除与空结果检查；现有测试 |
| 每日新增 | 数据加载状态；初始化至最新有效月份和日期；选中状态、空状态与来源列表 | 异步日期初始化回归测试；跨月与无数据检查 |
| 管理更新 | 表单和结果阅读优化；清晰区分运行、成功和失败 | 使用既有测试或隔离样例；不提交真实更新 |
| 通知与共享详情 | 统一提示、关闭按钮、来源与证据标识；修复通知入口跨页切换 | 入口切换及弹层键盘检查 |

## 实施顺序

1. 整理共享导航状态和设计变量，建立独立的统一样式层，避免扩大旧样式覆盖链。
2. 优化目录、详情与搜索页面，保持既有确定性筛选和来源字段。
3. 修复每日新增异步初始化，补充必要的行为回归验证。
4. 优化管理、通知、空状态、键盘焦点和小屏布局。
5. 运行前端构建和现有 Node 测试；能运行浏览器时检查所有活动页面，并记录无法验证的部分。
